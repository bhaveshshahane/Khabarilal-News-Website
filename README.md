# Khabrilal - हिंदी न्यूज़ वेबसाइट 📰🇮🇳

**Khabrilal** is a Hindi news website built using **Core PHP**, **MySQL**, and **Bootstrap**. It provides a responsive and easy-to-use platform for publishing and viewing the latest news across various categories such as politics, sports, entertainment, and technology.

## 📌 Features

- 🗞️ Hindi language support for wide audience reach
- 🧩 Admin panel to manage categories, news posts, and users
- 📚 CRUD operations for news articles
- 📸 Image upload and thumbnail display
- 🔍 News search and category-based filtering
- 📱 Fully responsive layout using Bootstrap
- 📅 News post date and time display
- 🔐 Secure login system for admin users

## 🚀 Technologies Used

- **Frontend:** HTML5, CSS3, Bootstrap 5
- **Backend:** Core PHP (Procedural or OOP)
- **Database:** MySQL
- **Other:** JavaScript, jQuery (if any), Font Awesome
